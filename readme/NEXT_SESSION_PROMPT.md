# Точка входа: плата шаговых двигателей

Актуально на 2026-10-30. Работы остановлены пользователем до переделки платы.
Сначала прочитать [отчёт остановки](STOP_POINT_2026-10-30.md).

- Вращение не подтверждено; UART отвечает только эхом.
- Последний стенд: один драйвер, выход7 / motor_id6, USART2 адрес0.
- STEP/EN на стороне МК проверены через ST-LINK; доставка STEP к драйверу не доказана.
- D103/D106 доступны по index2 (USART1) и6 (USART2); кнопка Studio читает RAM-снимок.
- Следующая работа — сверка новой схемы, адресов MS1/MS2 и распиновки; затем адаптация
  менеджера для восьми драйверов и аппаратная проверка. Не запускать/прошивать автоматически.
- Старые указания «следующий шаг — прошить/проверить текущую плату» отменены этой остановкой.

Основной отчёт проекта: readme/README.md. Общие отчёты находятся в соседнем
DDS-240_readme/DDS-240_eko_system/Step_motors; это каталог вне Git данного проекта.
